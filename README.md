## ✦ Quick Install

Clone once, run instantly:

```bash
git clone https://github.com/Dzakiamriz22/frontend-pack.git \
  ~/.config/opencode/plugin/frontend-pack
```

Add to `~/.config/opencode/opencode.json`:

```json
{
  "plugin": ["./plugin/frontend-pack"]
}
```

Restart OpenCode. Done.

> 📖 Full walkthrough → [`installation.md`](installation.md)

## ✦ Quick Start

```bash
/design landing        # Landing page with hero, features, testimonials
/dashboard admin       # Analytics dashboard with charts and tables
/auth login            # Login/register with validation and OAuth
/table users           # Sortable, searchable, paginated data table
/form checkout         # Multi-step checkout with validation
/ui-review             # Score current UI and auto-fix issues
/refactor-ui           # Fix accessibility, dark mode, states
/animate page          # Smooth page transitions
```

## ✦ All Commands

| Command | What it generates |
|---|---|
| `/design` | Any page or component — blank canvas |
| `/dashboard` | Analytics, admin, or metrics dashboard |
| `/landing` | Marketing site with hero, features, CTA |
| `/auth` | Login, register, forgot/reset password |
| `/profile` | User profile with avatar, settings, danger zone |
| `/settings` | App settings with sections and server actions |
| `/table` | Data table with sort, filter, pagination, CRUD |
| `/form` | Simple or multi-step form with React Hook Form + Zod |
| `/pricing` | Pricing tiers, comparison, FAQ |
| `/sidebar` | Navigation sidebar with collapsible sections |
| `/navbar` | Top nav with mobile hamburger menu |
| `/footer` | Multi-column footer with links and newsletter |
| `/ui-review` | Full design audit scoring 8 dimensions |
| `/refactor-ui` | Auto-fix a11y, dark mode, spacing, states |
| `/mobile` | Mobile-optimize touch targets and layout |
| `/animate` | Page transitions, micro-interactions, scroll reveals |
| `/design-system` | Tokens, themes, component library setup |
| `/tailwind` | Layout recipes, responsive patterns, animation utilities |
| `/shadcn` | Component usage, customization, theming |
| `/react` | Server/client boundaries, hooks, composition |
| `/next` | App Router, data fetching, server actions |

## ✦ Key Skills

Every command auto-loads the relevant skills. Here are the core ones:

| Skill | Purpose |
|---|---|
| **design** | UI generation at Apple/Linear quality |
| **ui-review** | Design review with 1-10 scoring |
| **ai-slop-detector** | Detects and rewrites generic AI UI |
| **typography** | Type scale, font pairing, rhythm |
| **color-system** | OKLCH palettes, accessible contrast |
| **spacing** | 4px/8px grid, layout consistency |
| **accessibility** | WCAG 2.1 AA compliance |
| **shadcn** | shadcn/ui component patterns |
| **framer-motion** | Production animation patterns |
| **forms** | React Hook Form + Zod validation |
| **tables** | TanStack Table with pagination |
| **performance** | Core Web Vitals, bundle optimization |

Each skill lives in `skills/<name>/SKILL.md` with full system prompt, rules, examples, and best practices.

## ✦ Design Standards

All generated UI benchmarks against the best in the industry:

| Company | What we learn from them |
|---|---|
| **Apple** | Pixel-perfect alignment, precise vertical rhythm, thoughtful negative space |
| **Linear** | Functional minimalism, generous whitespace, clean monochromatic palette |
| **Vercel** | Bold geometric layouts, large typography, strong grid systems |
| **Stripe** | Clear hierarchy, documentation-grade clarity, consistent left margins |
| **Notion** | Readable content-first layouts, flexible composition, minimal chrome |
| **GitHub** | Dense but scannable information, responsive tables, excellent mobile nav |
